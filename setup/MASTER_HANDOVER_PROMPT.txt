4. CRITICAL ARCHITECTURAL RULES & INVARIANTS
================================================================================
1. Role-Based Access Control (RBAC) Hierarchy (src/utils/rbac.ts):
   - Strictly respect the Marathi rank hierarchy:
     अध्यक्ष (Rank 1) > उपाध्यक्ष (Rank 2) > खजिनदार (Rank 3) > उपखजिनदार (Rank 4) > सदस्य (Rank 5) > सभासद (Rank 6) > पाहुणा / Guest (Rank 7).
   - Financial write permissions are strictly limited to financial roles (अध्यक्ष, खजिनदार, उपखजिनदार, ॲडमिन, Admin).
   - Logged-out users default to the unauthenticated Guest state (पाहुणा).

2. Marathi UTF-8 BOM CSV & PDF Exports (src/utils/exportUtils.ts):
   - All CSV downloads must prepend UTF-8 BOM (\uFEFF) and follow RFC-4180 escaping so Marathi Devanagari text displays properly in Microsoft Excel without character corruption.
   - Clean printable statements use @media print rules in src/index.css to hide headers/sidebars and display clear print layouts.

3. Real-Time Firestore Sync:
   - UI views stay in sync with Firestore via onSnapshot subscriptions.
   - Never break empty array listener callbacks or local storage cache fallbacks.

4. Recent Core Features Implemented:
   - Day-wise Daily Cash Tally Table & Accordion Ledger (दिनांकनिहाय रोख सारांश व टॅली / रोजमेळ).
   - Committee Scope Filter: All vs My Transactions (restricts normal members to own daily transactions).
   - Pending Physical Receipts Deposit: Directly deposit duplicate pending receipt numbers upon entry.
   - Pending Approvals UI: Limit pending approval transactions to 5 items with inline expand toggle & "see all" options on the dashboard.
